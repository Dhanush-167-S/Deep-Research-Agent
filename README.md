# TopResearch

> **Research Smarter. Think Deeper.**

TopResearch is an AI-powered research operating system that turns complex questions into structured, source-backed research reports.

Instead of treating research as a single LLM prompt, TopResearch coordinates specialized AI agents through a multi-step research workflow:

**Plan → Search → Analyze → Verify → Write**

The goal is simple: give users an answer they can inspect, trace, and understand — not just a confident block of generated text.

# Features

## Deep Research

Submit a complex research question and let TopResearch break it into smaller research tasks before gathering evidence.

## Multi-Agent Research

Specialized agents handle different responsibilities:

| Agent | Responsibility |
|---|---|
| Planner | Decomposes the research question and creates a research plan |
| Searcher | Finds relevant web and academic sources |
| Researcher / Analyst | Extracts and organizes useful evidence |
| Verifier | Cross-checks evidence and detects unsupported claims |
| Writer | Produces the final structured research report |

The agents are coordinated through a stateful workflow rather than being independent chatbots.

## Web Search

TopResearch uses **Tavily** as the primary web-search provider.

Search results become research sources that can be analyzed, verified, and cited.

## Academic Research

The research system can integrate academic sources such as:

- Semantic Scholar
- arXiv
- Other academic providers added through the search/provider abstraction

## Source Verification

Retrieved sources are tracked independently from generated prose.

The verification stage can check:

- Source accessibility
- Source metadata
- Evidence relevance
- Claim/source relationships
- Conflicting evidence
- Unsupported claims

## Citation Provenance

Research claims should map back to actual retrieved source records.

The report renderer resolves citations from stored source metadata rather than trusting arbitrary URLs generated by the LLM.

## Structured Reports

Research results are normalized into a structured report before being rendered.

The application should never dump raw LLM Markdown directly into the UI.

Reports support:

- Executive summary
- Sections
- Key findings
- Tables where appropriate
- Inline citations
- References
- Conclusions
- Source metadata

## Export

Completed reports can be exported as:

- PDF
- Markdown

Exports use the same normalized report structure shown in the web application.

## Streaming Research Progress

Users can observe research execution in real time:

1. Planning
2. Searching
3. Reading / extraction
4. Verification
5. Writing
6. Report completion

## Research History

Authenticated users can access previous research jobs and reports.

## Follow-up Research

Users can continue asking questions about an existing research report and its sources.

## RAG

TopResearch can use retrieval-augmented generation for relevant stored research knowledge and conversation/report context.

## Memory

The system can retain useful research context so follow-up interactions do not need to reconstruct the entire context from scratch.

## Authentication

Authentication is handled through Better Auth with:

- Email/password
- Google OAuth 2.0
- GitHub OAuth 2.0

Authenticated users are redirected to the research application rather than remaining on the public marketing site.

| SQLAlchemy | Database ORM / data access |
| LangChain | LLM, tool and retrieval abstractions |

## Database

| Technology | Purpose |
|---|---|
| PostgreSQL | Primary relational database |
| pgvector | Vector storage and similarity search |

## AI

### Primary LLM

**Google Gemini**

Gemini is the primary model provider for TopResearch.

### Optional / Fallback LLM

**Groq**

Groq can be configured as a fallback or alternative model provider when required.

### Embeddings

**Hugging Face**

Hugging Face-hosted embedding models are used for vector representations.

Embeddings are generated by the backend and stored in PostgreSQL/pgvector.

## Search

### Primary Web Search

**Tavily**

Tavily is the primary web-search provider for the initial production version.

The search layer uses an abstraction so additional providers can be added later without rewriting the Search Agent.

## Authentication

**Better Auth**

Providers:

- Google OAuth 2.0
- GitHub OAuth 2.0
- Email/password

## Observability

**LangSmith**

Used for tracing and debugging LLM and agent execution.
